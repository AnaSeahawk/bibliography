# Reading List — Sovereign Biophysics Archive

Books sourced to deepen and cite the archive, organized by topic. This is the
public catalog of the whole library.

- **Acquired** — public-domain book, held in this repo under its topic folder.
- **Acquired (private shelf)** — copyrighted or uncertain-rights book, held on
  Ana's private Google Drive shelf under the same topic folder name, with a
  fuller entry in that folder's `CATALOG.md`.
- **Listed under `folder/`** — the book belongs to this topic too, but is
  stored once, in the folder named.

## How the shelf is organized

1. **One book, one folder.** Each book is stored in exactly one topic folder,
   the one its bold scope line fits best. A book that also serves another
   topic gets a *Listed under* row there instead of a second copy.
2. **The scope line decides.** Each section opens with its folder's scope in
   bold. File a new book by that line; if no line fits, propose a new folder
   rather than stretching one.
3. **Public only when public domain.** A book stays in this repo only when its
   edition is public domain or openly licensed (check the edition, not just
   the original's date). Anything copyrighted or uncertain goes to the
   private shelf.
4. **Filenames:** `Author-Short-Title.ext`.
